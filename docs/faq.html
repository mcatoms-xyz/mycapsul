Basics

The Fundamentals

▸ What is MyCapsul?
A personal life dashboard your AI maintains through conversation. You talk about your life — schedule, money, health, projects — and the dashboard stays current. One HTML file in your browser, fed by local files your AI reads and writes.
▸ Is MyCapsul an app I need to install?
Not in the traditional sense. Download the MyCapsul zip file from mycapsul.com, point Cowork at the extracted folder during setup. The dashboard is an HTML file you open in your browser. No app store, no installer, no account, no cloud.
▸ Do I need to know how to code?
No. You talk to your agent in plain language — "add a bill for $85 on the 15th" — and it handles the technical side. Want something custom? Describe it and your agent builds it.
▸ What AI does MyCapsul use?
MyCapsul currently runs on Claude (by Anthropic) through Cowork (Anthropic's desktop environment). Sonnet works; Opus is recommended. MyCapsul has no AI of its own — it gives Claude a framework and a knowledge system to run your life from.
▸ How much does it cost?
MyCapsul is available at mycapsul.com. You'll also need a Claude Desktop subscription from Anthropic. MyCapsul itself has no fees or subscriptions.
Sessions

Working With Your Agent

▸ How does my agent remember things between sessions?
Through seed modules — plain-text files in your folder that hold everything about your life (schedule, finances, health, and so on). Each new session, your agent reads them plus a session handoff file that briefs it on what happened last time.
▸ Do I need to start a new session every time?
Yes — each Cowork session is a new conversation. The handoff file and seed modules restore context, so it feels continuous. Think shift change: every shift starts with a briefing from the last one.
▸ What if I forget to mention something during a session?
Mention it next session. "I forgot to tell you — I paid the electric bill last Tuesday." Your agent updates the record retroactively.
▸ Can I have multiple sessions per day?
Yes. Your agent checks how long it's been since the last session. Same-day sessions get a Quick Resume; sessions after a gap get a Full Boot that reviews every module.
▸ What happens at the end of a session?
Your agent updates the seed modules with anything new, syncs changes to the dashboard, and writes a handoff file for next time. You don't have to ask.
Dashboard

The Dashboard

▸ How do I get changes from my agent to show up on the dashboard?
Your agent writes changes to a push file (capsul-agent-push.js). Refresh the dashboard and it applies them. (Live 5-second polling only works if you serve the folder over http; opened directly, the normal way, it's refresh-only.)
▸ Can I edit things directly on the dashboard?
Yes. Check off Focus 3 items, mark bills paid, toggle hobbies, edit journal entries. Changes save to localStorage. Click Sync to export them so your agent sees them next session.
▸ What are the different palettes?
MyCapsul ships with seven color palettes: MyCapsul (brand blue, default), Ocean (teal), Sunset (warm orange), Forest (green), Lavender (purple), Amber (gold), and Slate (blue-gray). Tell your agent "switch to sunset," or change it in dashboard settings.
▸ Can I rearrange or hide widgets?
Yes. Tell your agent "hide the news widget" or "move budget to the top." You can also toggle visibility in the dashboard's widget manager. There are 17 built-in widgets, plus any add-ons you install.
▸ What is the ring clock?
The Ring is a 24-hour circular schedule planner. Your day as colored arcs — work, personal time, appointments, sleep — generated each session from your schedule module. Click the Ring to edit any day's blocks. Each block's category (work, build, family, admin, personal, break) sets its color.
▸ What is TimeCapsul?
TimeCapsul is a year-in-review feature. Access it from the "View TimeCapsul" button on the Timeline widget. It builds a visual summary of your year: monthly highlights, goal progress, journal excerpts, finished projects. Your agent adds monthly summaries through the year by writing the tcAgent_YYYY key (documented in the agent skill).
▸ What are the sync files and how do they work?
Two files, both in _inbox/. capsul-sync.json (dashboard → agent) exports your dashboard state; you trigger it with "Sync Now" in Settings (automatic sync needs Chrome or Edge — other browsers download the file instead). capsul-agent-push.js (agent → dashboard) carries your agent's commands, which the dashboard loads on refresh.
▸ What do the ℹ️ buttons on widgets do?
Open a short guide to that widget: what it does, how to use it, and things to tell your agent.
Data, Privacy & Security

Your Data Is Yours

▸ Where is my data stored?
Everything stays on your computer. Setup creates a MyCapsul/ directory in the folder you pick. Seed modules are Markdown files in MyCapsul/seed/; MyCapsul/_inbox/ is where you drop files for your agent and where the sync files live. The dashboard keeps widget data in your browser's localStorage. Nothing is uploaded to any server — no cloud, no account, no database. (The page itself loads its fonts from Google/Adobe, and optional live tiles like News, Weather, and Stocks call third-party services with the URLs, location, or symbols you configure.)
▸ My files are plain text — is that a security risk?
Not by itself. Local plain text is how Obsidian, Logseq, and password-manager vaults work too. Anyone who can read your files can already read your browser passwords, email, and photos. The real lock is your operating system: login password and disk encryption (FileVault on Mac, BitLocker on Windows). MyCapsul doesn't add a second lock — it would add friction without real security and stop you and your agent editing your own files.
▸ Can anyone else see my data?
Only with access to your computer. No sharing feature, no cloud sync, no remote access — it's as private as any other file on your machine. If you share the computer, password-protect your user account.
▸ Should I keep my folder in iCloud / Google Drive / Dropbox?

Careful. If the folder sits inside a cloud-synced directory, your seed modules — finances, health, schedule — are being uploaded to that provider. This is the most common way local data becomes cloud data by accident.

If privacy matters, keep the folder somewhere non-synced, like your home directory. If you do want cloud backup, know the provider's privacy terms.

▸ Does my AI send my data to Anthropic?
Your conversations go through Anthropic's servers — that's how Claude works — and whatever your agent reads from your folder during a session becomes part of that conversation. Your files themselves are not uploaded beyond what's read. Retention is governed by Anthropic's privacy policy for details on retention and handling.
▸ What about the dashboard's localStorage?
Widget data lives in localStorage, keyed to the HTML file's path. Anyone opening that file in the same browser profile sees it — standard browser behavior. Clearing browser data erases dashboard state, but your seed modules are unaffected and your agent can repopulate from them.
▸ How do I back up my Capsul?
Copy the MyCapsul folder. Everything is files — dashboard, seed modules, widgets, agent config — so it's all portable. Export a sync before big changes.
▸ What if I want to share my setup without sharing my personal data?

The easiest way? Send them to mycapsul.com for the latest release. They get a clean copy and none of your data tags along.

To share your own setup, share the structure, not the content. Safe: mycapsul.html, SKILL.md, custom widget files. Not safe: anything in seed/, capsul-sync.json, capsul-agent-push.js, CLAUDE.md, and session-handoff.md. A blank journal, not a filled one.

▸ How do I secure my computer to protect my Capsul data?
(1) A strong login password. (2) Disk encryption — FileVault on Mac (System Settings → Privacy & Security → FileVault), BitLocker on Windows (Settings → Privacy & Security → Device encryption) — so the drive can't be read even if it's pulled out. (3) Lock your screen when you walk away. That covers every file on the machine, not just MyCapsul.
Troubleshooting

When Things Go Wrong

🛠
Your Capsul agent is your first line of support. Describe what's wrong in plain language before working through the steps below; it can diagnose and fix most issues. Sonnet works; Opus (or its current equivalent) is recommended for the best results.
▸ My agent doesn't seem to know what happened last session
Check that session-handoff.md exists and has recent content — that's what your agent reads for context. If it's missing or empty, say "read my seed modules and get caught up."
▸ Changes from my agent aren't showing on the dashboard
(1) Refresh the page — the push file loads on refresh (live polling only works over http, not when the file is opened directly). (2) Check that capsul-agent-push.js exists in _inbox/. (3) Open dev tools (F12) and check the console for errors.
▸ My dashboard looks empty after opening in a new browser
Dashboard data lives in localStorage, which is per-browser. A different browser (or cleared data) starts empty. Ask your agent to "sync from the dashboard" if you have a recent capsul-sync.json, or to repopulate from the seed modules.
▸ I messed up my dashboard — can I undo?
Ask your agent. If the change came from a push, it can push a revert. If you edited it in the UI, fix it by hand or ask your agent to reset that widget.
▸ The sync button isn't working
Sync writes localStorage to capsul-sync.json in _inbox/. If it isn't: (1) Make sure you opened the HTML file from your MyCapsul folder, not a copy. (2) Automatic sync needs Chrome or Edge — other browsers download capsul-sync.json to Downloads instead; move it into _inbox/ yourself. (3) Check that _inbox/ exists.
Advanced

Going Deeper

▸ Can I use MyCapsul with a different AI?
In principle. Everything is local markdown and JSON, so any AI that reads and writes files could run it; you'd adapt SKILL.md and CLAUDE.md to that AI's conventions. Today it's built for Claude via Cowork.
▸ What are widgets?
Add-ons for the dashboard. They're .capsul-widget files; drop one in widgets/ and tell your agent to install it. Only install widgets from sources you trust — a widget runs as code inside your dashboard with access to all of its data. Or describe one and your agent builds it.
▸ Can I connect email, calendar, or other services?
If your Cowork session has connectors enabled (Gmail, Google Calendar, Google Drive, Slack), your agent can read them and route what it finds into your seed modules. Optional; MyCapsul works without them.
▸ Can I edit the seed files directly?
Yes. They're plain markdown; open them in any text editor. Your agent sees changes next session. Keep the headings intact so it can still parse them.
▸ How do I change my agent's personality?
Edit your CLAUDE.md file, or tell your agent directly: "Be more casual," "Don't ask me so many questions," or "Change your name to Jarvis." Your agent writes these to CLAUDE.md, its operating manual, and reads it every session.
▸ What's the demo file for?
mycapsul-demo.html is the dashboard filled with sample data from a fictional user named "Brodie" — budget, schedule, projects, goals, journal — so you can see a finished Capsul before setting up your own. Open mycapsul-demo.html directly; it ships next to mycapsul.html.
